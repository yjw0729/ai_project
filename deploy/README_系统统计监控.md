# RAG系统统计监控功能

## 📊 功能概述

为了解决向量数据库"黑盒子"问题，我们为RAG系统添加了完整的统计监控功能，让您可以清楚地了解系统中的数据存储情况。

## 🎯 解决的问题

### ❓ 传统问题
- **看不到数据量**: 不知道存储了多少文档和文本块
- **存储空间未知**: 不清楚向量数据库占用了多少磁盘空间
- **业务分布模糊**: 无法了解不同业务模块的数据分布
- **性能监控缺失**: 缺乏系统运行状态的监控

### ✅ 我们的解决方案
- **实时统计**: API接口实时查询系统状态
- **可视化监控**: 命令行监控面板直观显示
- **业务模块统计**: 按模块查看数据分布
- **存储空间监控**: 详细的磁盘使用情况

## 🛠️ 技术实现

### 统计数据来源

1. **集合信息**: 从向量数据库元数据获取
2. **业务模块统计**: 通过查询向量数据库中的业务模块标签计算
3. **存储空间**: 扫描本地文件系统目录
4. **系统资源**: 使用psutil库获取磁盘和系统信息

### 实时性保证

- **缓存策略**: API响应包含时间戳，避免频繁查询
- **异步更新**: 统计计算不阻塞主业务流程
- **错误处理**: 单个统计项失败不影响整体功能

### 扩展性设计

- **插件化架构**: 支持添加新的统计指标
- **配置驱动**: 通过配置文件控制显示的统计项
- **多数据源**: 支持从不同向量数据库获取统计信息

## 📈 监控指标详解

### 核心指标

| 指标 | 说明 | 重要性 |
|------|------|--------|
| 集合数量 | 向量数据库中的集合总数 | ⭐⭐⭐ |
| 总文本块 | 系统中的文本块总数 | ⭐⭐⭐ |
| 向量维度 | 向量嵌入的维度数 | ⭐⭐⭐ |
| 存储大小 | RAG相关文件占用的磁盘空间 | ⭐⭐⭐ |
| 业务模块分布 | 各业务模块的数据量分布 | ⭐⭐⭐ |

### 性能指标

| 指标 | 说明 | 监控频率 |
|------|------|----------|
| 查询响应时间 | API响应的平均时间 | 实时 |
| 存储增长率 | 每日数据增长量 | 每日 |
| 错误率 | 系统错误发生率 | 实时 |

## 🔧 使用指南

### 日常监控

1. **定期检查**: 每周查看系统概览
2. **存储监控**: 关注磁盘使用率，避免空间不足
3. **业务平衡**: 确保各业务模块数据分布合理

### 故障排查

1. **存储异常**: 检查存储统计，定位大文件
2. **性能问题**: 查看集合统计，考虑优化分块策略
3. **数据不一致**: 对比业务模块统计和实际使用情况

### 容量规划

1. **存储规划**: 根据当前使用率预测未来需求
2. **性能优化**: 监控查询响应时间，优化索引策略
3. **扩展准备**: 根据数据增长趋势规划系统扩展

## 📝 注意事项

1. **性能影响**: 统计查询会消耗少量系统资源
2. **缓存策略**: 统计数据有轻微延迟，不是完全实时
3. **权限控制**: 生产环境建议添加访问控制
4. **监控告警**: 建议设置存储空间和错误率的告警
