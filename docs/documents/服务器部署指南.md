# PyTest SXP 项目服务器部署指南

本文档详细介绍如何将PyTest SXP项目部署到生产服务器环境。

## 项目概述

PyTest SXP是一个基于Flask的Web应用，提供以下服务：
- 测试数据生成服务（银行卡号、地址、身份证号、客户信息等）
- AI服务（测试用例生成、文档解析等）
- 数据库配置管理
- 测试执行管理

## 1. 服务器环境准备

### 1.1 安装Python环境
```bash
# 更新系统包
sudo apt update && sudo apt upgrade -y

# 安装Python 3.8+ 和pip
sudo apt install python3 python3-pip python3-venv -y

# 安装系统依赖（根据requirements.txt中的库）
sudo apt install python3-dev build-essential libssl-dev libffi-dev -y
```

### 1.2 安装其他必要工具
```bash
# 安装git（用于代码管理）
sudo apt install git -y

# 如果需要数据库（如MySQL/PostgreSQL）
sudo apt install mysql-server postgresql -y
```

## 2. 上传项目代码

### 2.1 创建项目目录
```bash
# 在服务器上创建项目目录
sudo mkdir -p /opt/pytest_sxp
cd /opt/pytest_sxp
```

### 2.2 上传代码
有几种方式上传代码：

**方式1：使用git（推荐）**
```bash
# 如果项目在git仓库中
git clone [your-repo-url] .

# 或者上传本地代码
# 使用scp、rsync或FileZilla等工具上传整个项目文件夹
```

**方式2：压缩上传**
```bash
# 本地压缩项目
tar -czf pytest_sxp.tar.gz /path/to/your/project

# 上传到服务器
scp pytest_sxp.tar.gz user@server:/opt/

# 服务器解压
cd /opt
tar -xzf pytest_sxp.tar.gz
mv pytest_sxp/* pytest_sxp/
```

## 3. 配置Python环境

### 3.1 创建虚拟环境
```bash
cd /opt/pytest_sxp
python3 -m venv venv
source venv/bin/activate
```

### 3.2 安装依赖
```bash
# 激活虚拟环境
source venv/bin/activate

# 安装项目依赖
pip install -r requirements.txt

# 如果还有其他依赖，根据错误提示安装
pip install flask gevent
```

## 6. 测试启动

### 6.1 测试运行

## 7. 配置生产环境运行

### 7.1 创建systemd服务
```bash
# 创建服务文件
sudo nano /etc/systemd/system/pytest-sxp.service
```

服务文件内容：
```ini
[Unit]
Description=PyTest SXP Flask Application
After=network.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/opt/pytest_sxp
Environment="PATH=/opt/pytest_sxp/venv/bin"
ExecStart=/opt/pytest_sxp/venv/bin/python app/run.py
Restart=always

[Install]
WantedBy=multi-user.target
```

### 7.2 启动服务
```bash
# 重新加载systemd
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start pytest-sxp

# 设置开机自启
sudo systemctl enable pytest-sxp

# 查看状态
sudo systemctl status pytest-sxp
```

### 7.3 配置Nginx反向代理（可选但推荐）
```bash
# 安装Nginx
sudo apt install nginx -y

# 创建配置文件
sudo nano /etc/nginx/sites-available/pytest-sxp
```

Nginx配置内容：
```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:8015;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
# 启用配置
sudo ln -s /etc/nginx/sites-available/pytest-sxp /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启Nginx
sudo systemctl restart nginx
```

## 8. 安全配置

### 8.1 防火墙设置
```bash
# 允许HTTP和HTTPS
sudo ufw allow 80
sudo ufw allow 443
sudo ufw allow 8015  # 如果直接暴露Flask端口

# 启用防火墙
sudo ufw enable
```

### 8.2 SSL证书（推荐）
```bash
# 安装Certbot
sudo apt install certbot python3-certbot-nginx -y

# 获取免费SSL证书
sudo certbot --nginx -d your-domain.com
```

## 9. 监控和维护

### 9.1 日志查看
```bash
# 查看应用日志
sudo journalctl -u pytest-sxp -f

# 查看项目日志
tail -f /opt/pytest_sxp/logs/app_flask.log
```

### 9.2 备份策略
```bash
# 创建备份脚本
sudo nano /opt/backup-pytest-sxp.sh
```

备份脚本内容：
```bash
#!/bin/bash
BACKUP_DIR="/opt/backups"
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p $BACKUP_DIR

# 备份数据库（如果有）
mysqldump -u pytest_user -p'your_password' pytest_sxp > $BACKUP_DIR/db_$DATE.sql

# 备份项目文件
tar -czf $BACKUP_DIR/project_$DATE.tar.gz /opt/pytest_sxp

# 清理7天前的备份
find $BACKUP_DIR -name "*.sql" -mtime +7 -delete
find $BACKUP_DIR -name "*.tar.gz" -mtime +7 -delete
```

```bash
# 设置执行权限并添加到crontab
sudo chmod +x /opt/backup-pytest-sxp.sh
sudo crontab -e
# 添加：0 2 * * * /opt/backup-pytest-sxp.sh
```

## 快速部署脚本

为了简化部署过程，您可以创建一个自动化部署脚本：

```bash
#!/bin/bash
# deploy.sh - 自动化部署脚本

echo "开始部署PyTest SXP..."

# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装依赖
sudo apt install python3 python3-pip python3-venv git nginx -y

# 创建项目目录
sudo mkdir -p /opt/pytest_sxp
cd /opt/pytest_sxp

# 克隆或上传代码
# git clone [your-repo-url] .

# 创建虚拟环境并安装依赖
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 配置systemd服务
sudo cp deploy/pytest-sxp.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable pytest-sxp
sudo systemctl start pytest-sxp

# 配置Nginx
sudo cp deploy/nginx.conf /etc/nginx/sites-available/pytest-sxp
sudo ln -s /etc/nginx/sites-available/pytest-sxp /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx

echo "部署完成！"
```

## 故障排除

### 常见问题

1. **端口占用**
   ```bash
   # 查看端口占用
   sudo netstat -tlnp | grep 8015
   # 杀死进程
   sudo kill -9 PID
   ```

2. **权限问题**
   ```bash
   # 修改文件权限
   sudo chown -R www-data:www-data /opt/pytest_sxp
   ```

3. **依赖问题**
   ```bash
   # 重新安装依赖
   source venv/bin/activate
   pip install --force-reinstall -r requirements.txt
   ```

4. **数据库连接问题**
   - 检查数据库服务状态
   - 验证连接字符串
   - 检查防火墙设置

### 日志位置
- 系统日志：`/var/log/syslog`
- Nginx日志：`/var/log/nginx/`
- 应用日志：`/opt/pytest_sxp/logs/`
